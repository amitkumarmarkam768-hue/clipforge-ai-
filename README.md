# ClipForge AI

Mobile-friendly automatic video clip generator. Upload a video you own or have permission to edit, or provide a direct public video-file URL.

**YouTube:** Normal YouTube watch links are not directly downloadable by this starter. Do not use this app to bypass YouTube access controls. Authorized YouTube account import would need a separate OAuth integration.

Free CPU hosting may be slow and may restart or lose temporary files. The current MVP uses Whisper tiny and FFmpeg.
